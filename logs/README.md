# Conversation Logs Directory

This directory stores all completed conversation sessions generated by the **Loop Engineering Chatbot** in Markdown format.

## File Naming Convention
Each session file is named using the starting date and time:
`YYYY-MM-DD_HH-mm-ss.md`

Example:
`2026-09-03_11-20-45.md`

## Structure of each Log File
1. **Metadata**: Start time, model used, total loop iterations, duration, and tool count.
2. **User Prompt**: The original request from the operator.
3. **Autonomous Loop Tool Calls & Observations**: Every step's tool call, arguments, and returned observation.
4. **Final Synthesized Answer**: The complete reasoning conclusion delivered to the user.
